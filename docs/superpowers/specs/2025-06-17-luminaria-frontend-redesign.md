# LuminAria 前端重新设计 — 维多利亚古典风格

## 概述

对 LuminAria 前端进行全面的视觉重新设计和功能增强。设计风格定为 **维多利亚古典**（Victorian Classical），以暗色底 + 鎏金装饰 + 衬线/花体中文字体为核心视觉语言。

## 新增功能

### 1. 时长滑块 + 快捷按钮

**交互方式：**
- 可拖动的滑块控制输出时长（15s–120s，步长 5s），拖动时右侧实时显示当前秒数
- 保留4个快捷按钮（30秒 / 60秒 / 90秒 / 120秒），点击按钮同时更新滑块位置
- 滑块和按钮共享同一状态，双向同步

**视觉风格：**
- 鎏金渐变轨道（`#8b7433` → `#c9a84c`），深色背景（`#2a2520`）空轨
- 复古雕刻感旋钮：径向渐变铜金色，深色边框，金色发光阴影
- 刻度标签：15秒 / 30秒 / 60秒 / 90秒 / 120秒，细弱字体
- 快捷按钮用 `Noto Serif SC` 衬线字体，选中态金色边框 + 极淡金色背景

### 2. 一键删除全部历史

**交互方式：**
- "删除全部记录"按钮位于历史列表底部，独立区域，用暗红警告色
- 点击后弹出维多利亚风格确认弹窗
- 弹窗包含：上方装饰符号（✧）、"确认删除"标题、描述文字、"取消"和"确认删除"两个按钮
- 确认后调用后端批量删除 API，前端刷新列表

**后端变更：**
- `database.py` 新增 `delete_all_generations()` 函数
- `main.py` 新增 `DELETE /api/history` 端点（无 `{id}` 后缀），删除所有记录及对应音频文件

### 3. 优化后提示词可折叠

**交互方式：**
- 默认收起状态：只显示装饰性标题栏
- 点击标题栏展开/收起，带动画过渡
- 展开时内容区域从标题栏下方"垂落"，左右有细金线边框

**视觉风格：**
- 标题栏：左右各一个 ⚜️ 装饰符号，中间"优化后提示词"字样，右侧箭头指示状态
- 收起时箭头朝右（❮），展开时箭头旋转向下
- 收起/展开切换带 `max-height` CSS transition

### 4. 维多利亚风格音频播放器

**视觉风格：**
- 参考黑胶唱机设计：圆形黑胶唱片装饰（同心圆 + 铜色中心标签）
- 播放/暂停按钮：44px 金色渐变圆形旋钮，带发光阴影
- 时间码：等宽字体（monospace），当前时间 / 总时长
- 前进 / 后退按钮：位于播放按钮两侧
- 音量控制：小喇叭图标 + 铜色音量条
- 整体卡片：深色底 + 双线金色边框，投影营造浮起感

## 字体系统

- **Logo / 大标题：** `ZCOOL QingKe HuangYou`（站酷文艺体）— 花体手写感
- **正文 / 标签：** `Noto Serif SC`（思源宋体）— 典雅衬线
- **时间码：** `monospace` — 等宽数字
- **回退：** serif / cursive 逐级回退

## 动画与过渡

- 滑块旋钮：`transition: left 0.15s ease`
- 折叠提示词：`max-height` + `opacity` transition（0.3s ease）
- 按钮 hover：金色发光增强 + 微上移
- 弹窗出现：`opacity` + `scale`（0.2s ease）
- 进度条：`transition: width 0.3s ease`

## 后端变更清单

1. **`app/config.py`** — 新增 `MIN_DURATION_SECONDS = 15`，`DURATION_STEP = 5`
2. **`app/database.py`** — 新增 `delete_all_generations()` 函数
3. **`app/main.py`** — 新增 `DELETE /api/history` 端点（批量删除）

## 前端文件变更

1. **`static/index.html`** — DOM 结构调整：播放器替换为复古风格，添加折叠提示词结构，历史面板标题居中
2. **`static/style.css`** — 大幅重写：新色彩系统、字体导入、播放器样式、弹窗样式、动画
3. **`static/script.js`** — 滑块逻辑、折叠切换、批量删除 API 调用、弹窗确认
